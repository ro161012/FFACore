# FFACore Resource Pack

Combined resource pack: the **FFACore** custom-item assets merged on top of
 the **AltarSMP** pack (remake by _Duckzy_). It ships everything AltarSMP
provides — weapon models, textures, sounds, item dispatches, tooltip sprites —
plus FFACore's animated gradient tooltips for its two currencies. Enable this
one pack instead of both.

The Kill Token and AFK Shard render as their base vanilla items (Nether Star
and Echo Shard) and ship no custom textures or model data. The configurable
ability weapons also render as their base vanilla items (their
custom-model-data range, `910xxx`, maps to the base models in the dispatches).

## Contents

### AltarSMP (merged as-is)

| Path | Purpose |
|---|---|
| `assets/altar/`, `assets/custom/` | AltarSMP weapon models, textures, sounds |
| `assets/minecraft/items/*.json` | AltarSMP item model dispatches |
| `assets/minecraft/models/weapons/`, `models/custom/` | Weapon models |
| `assets/minecraft/textures/item/altar/` | Weapon textures |
| `assets/minecraft/textures/gui/sprites/tooltip/` | AltarSMP tooltip sprites |

### FFACore additions

| Path | Purpose |
|---|---|
| `assets/altarsmp/textures/gui/sprites/tooltip/cutlass_*.png` | Animated ocean-blue tooltip (AFK Shard, 20 frames) |
| `assets/altarsmp/textures/gui/sprites/tooltip/bloodlust_*.png` | Animated ember-red tooltip (Kill Token + block, 20 frames) |

## Installation

1. Build the pack with `./mvnw package` (produces
   `target/FFACore-Resourcepack.zip`) or zip the `resourcepack/` folder
   yourself.
2. Place the zip in the server's `resourcepacks/` folder (or configure it as a
   server resource pack so players receive it automatically).

Targets Minecraft **1.21.11** (`min_format`/`max_format` 75). Since 1.21.9
Minecraft reads the new `min_format`/`max_format` fields instead of the
legacy `pack_format`/`supported_formats` — the old fields made the pack
show as incompatible on 1.21.11.

## How the gradient tooltips work

The display names of the Kill Token and AFK Shard use a smooth per-character
gradient, and the items carry a `minecraft:tooltip_style` data component:

* `altarsmp:cutlass` — ocean-blue animated tooltip (AFK Shard)
* `altarsmp:bloodlust` — ember-red animated tooltip (Kill Token + block)

The per-theme weapon tooltips were removed; custom ability weapons use the
vanilla default tooltip.

The pack icon is generated by `tools/generate-assets.mjs`
(`node tools/generate-assets.mjs`) and committed, so the pack builds without
a Node step.
